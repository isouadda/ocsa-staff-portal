# Bold names in guide/APP-PORTAL.md that the check lets through with no
# row in translation/portal_words.csv. One per line, written the way the
# guide writes it, **English** (**Spanish**) (**French**), under a comment
# line saying why it is here. A blank line ends what a comment covers.
# Spanish and French letters are \u escapes, the way src/words.js writes
# them, so this file stays ASCII; the check reads either. The French is
# what a French screen shows: for a name the portal composes, its own
# French; for a name the API serves, its English, since the API has no
# French and answers a French screen in English.
# npm run guide-check says when a name here is no longer in the guide.
